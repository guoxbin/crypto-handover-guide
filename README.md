# 加密资产家庭交接指南

## 1. 前言
目前家庭资产非常多样化，包括现金、存款、互联网钱包、债权、理财、股票、基金、保险等，一般这些资产交接障碍较小，提供方式如下： 
| 资产 | 提供方式 |
| --- | --- |
| 现金 | 放置位置 |
| 存款 | 银行卡、密码 |
| 互联网钱包 | 账户、密码 |
| 债权 | 借条、借款凭证等 |
| 理财 | 银行卡、密码 |
| 股票 | 股票账户、密码 |
| 基金 | 基金账户、密码 |
| 保险 |保险合同 |

但是，随着加密资产的出现，家庭资产进一步多样化。对于那些对加密资产了解较少的家庭成员，交接加密资产的挑战较大。 

本文旨在提供加密资产的说明，让读者获得交接加密资产所需要的基本知识。 

本文并不是一个操作清单，而是可以让读者根据获取的基本知识，具有迁移使用的能力，比如接触到新的交易所，新的去中心化应用也可以自主了解、理解和根据需要进行操作。

## 2. 加密资产
加密资产具有很深的技术和经济学内涵，如果要理解其运行原理，需要理解密码学，共识算法，网络通信，虚拟机等技术，如果要理解其价值来源，需要理解经济模型。 

好消息是，如果仅仅是交接加密资产，并不需要完整的理解上述内容，只需要理解如下内容： 

加密资产的本质只不过是利用“去中心化账本”记录了资产的账目，账目包含了余额，转账记录； 

在去中心账本上，并不维护也无法维护账户和真人之间的对应关系，拥有私钥就等价于拥有账户； 

传统的商业服务，账户只是为了方便管理而创建出来的真人的映射，最终有真实世界的机制保障真人的利益，而去中心化账本上，并不存在真实世界的保障机制，拥有私钥就有绝对的控制权，不拥有或者丢失私钥就毫无控制权，所以保管好私钥至关重要。 

访问[https://coinmarketcap.com/](https://coinmarketcap.com/) 可以很方便查阅各类加密资产，加密资产一般有一个Symbol和一个名称，比如比特币的Symbol是BTC，名称是Bitcoin，以太坊的Symbol是ETH，名称是Ethereum。 

## 3. 基础设施
类似于互联网世界，在加密世界中，也有一些专门的组织提供的基础服务，支撑了整个加密世界的运行。 

交接加密资产是绕不开这些基础设施的，可以说只有可以熟练的使用这些基础设施，才是加密世界的合格公民。 

### 3.1 科学上网
加密世界的应用和服务并不是在所有国家都合规，所以有些是需要通过科学上网才能访问的。 

建议就不要到处找免费的和蹭别人的代理了，花钱买一个良心的稳定的科学上网服务。 

### 3.2 手机号
虽然加密资产的底层是去中心化账本，不依赖于现实世界的身份信息，但是加密资产的一些派生系统为了对普通用户更加友好，是以传统的中心化系统的方式构建的，保留了传统中心化系统的使用方式。 

手机号常用于作为系统注册账号，在进行敏感操作时，均会要求填入下发的短信验证码。在加密世界中，因为是和资产打交道，安全和风控机制往往更严格，需要使用短信验证码的频率要比传统互联网服务高的多。 

要保持手机畅通，不要使用临时号码，不要使用有停机风险的不常用号码，不要嫌频繁的短信验证码麻烦就把手机交给别人打理。 

### 3.3 邮箱
和手机号一样，邮箱也常用于作为系统注册账号，在进行一些敏感操作时，会发送包含验证码的邮件。 

要使用信誉更好，更知名的邮件服务商，这样邮件的到达率和服务的持续性都更有保障。当无法按预期收到邮件时，可以检查下垃圾邮件，可以解决90%的问题。 

### 3.4 美版AppleID
因为AppleStore是分国家地区根据当地法规进行运营的，一些加密行业的App无法用中版下载，所以为了安装更可信的官方版本，需要美版的AppleID。建议直接淘宝购买。 

### 3.5 两步验证
一般来说，增加验证因素，是可以提升验证安全性的，所以为了进一步防范风险，加密世界的系统往往引入了两步验证，在进行一些敏感操作时，除了输入密码和进行短信验证或邮箱验证，还需要进行两步验证。 

最常用的两步验证是Google Authenticator，其官网是[https://www.google.com/landing/2step/](https://www.google.com/landing/2step/)。 

使用Google Authenticator首先需要安装其手机APP，可在Google Play或AppStore下载安装。 

在使用具有两步验证机制的系统时，在注册账号过程中，系统会提示开启两步验证，一般会提供一个二维码和一串密钥，二者是等价的。此时建议复制此密钥，打开Google Authenticator APP，在加号菜单中选择“输入设置密钥”，完成后APP首页会出现相应的条目，此条目是6位数字，每分钟刷新一次。后续在使用系统过程中，要求输入两步验证的时候，打开Google Authenticator APP，找到相应条目，将当时的6位数字填入即可。 

Google Authenticator APP中的信息仅在本地保存，所以当更换手机或者删除了APP的时候，这些信息全部都会丢失，所以一定要备份上述密钥，这样在任何时候都可以在新安装的Google Authenticator APP中恢复条目。如果遇到了密钥丢失，也有补救的办法，可以联系系统的服务商，服务商通过一些交叉信息验证的方式确定了你确实是账号主人时，是可以帮你更换一个私钥的，此过程非常麻烦，当你对自己账号的一些历史信息记忆的不大清楚的时候也很可能被驳回，所以最好的办法还是做好密钥的备份。 

### 3.6 手机钱包
前面介绍了私钥的重要性，而创建私钥，使用私钥来查看余额和转账都需要特定的工具，而手机钱包就是这种工具中的一种。 

现在的钱包一般是HD钱包，即分层确定性钱包，在这种钱包中，你使用的不是私钥，而是与他等效的助记词。助记词一般由12个英文单词或者12个汉字组成，钱包支持生成新的助记词和导入已有的助记词。 

钱包一般不会直接保存你的原始助记词，而是把助记词进行加密再进行保存，而加密的密码会提示你输入，并且也不会记录你的密码，即正经的钱包不会记录你的助记词，当需要使用你的助记词的时候，需要你输入密码，钱包临时解密出助记词继续使用。 

因为钱包产品都希望自己可以尽可能的覆盖大多数资产，而当今加密世界的协议，链和资产类型已经发展的非常丰富，即使钱包已经尽可能的提升易用性，钱包产品仍然非常复杂，对于新手来说仍然有一定的门槛，下面就介绍一些通用的特征，希望掌握了这些特征，使用任何一个钱包都不迷路，而且可以通过自我尝试实现掌握。 

 - 一般钱包都支持多个助记词，每个助记词对应一个身份，一般都提供了身份切换的地方。 
 - 每个身份下面可以列出了不同的协议，比如比特币，以太坊，波场等等，这些协议可以启用或关闭。 
 - 每个协议下面包含了这个协议支持的各种通证和与协议相关的内容，比如比特币协议下面就包含BTC和USDT（最初的USDT是基于BTC网络实现的），以太坊协议下面就包含了ETH和各种代币，波场协议下面就包含了TRX和各种代币，以及波场独有的能量和带宽状态。 
 - 协议一般只对应一个网络，但是随着发展，一些网络采用了兼容协议的方式，比如币安智能链就兼容了以太坊网络，所以如果要支持币安智能链，就可能有两种做法，一种是只提供以太坊协议，但是协议下面可以切换以太坊主网和币安智能链主网，比如钱包imToken，另一种是把币安智能链和以太坊并列，作为一种新协议，比如钱包TrustWallet。 
 - 钱包产品一般不会跳出上述的组织结构，只不过会根据自身的设计理念有一些调整。比如imToken里导入新身份要指定协议，避免了身份和协议的太多组合，降低了复杂性；又比如TrustWallet的一个身份下，会把所有协议下面的所有代币都打平到一个层次显示，也是为了降低复杂性。 

下面是一些使用原则： 
 - 要选择信誉比较好的钱包，最好是开源的经过了审计的钱包。 
 - 不要随便在一个未知网站下载手机APP，一定要去Google Play或AppStore下载。
 - 不要在公共区域的WiFi下操作钱包，最好使用手机蜂窝网络。
 - 钱包操作完之后，杀掉进程。 
 - 创建出助记词之后，要立刻备份，不要偷懒，不要拖延。
 - 操作转账的时候，一定要反复确认下接收地址，错了没有任何人可以帮你退回。 
 - 不要使用地址簿，加密世界没有那么稳定的接收地址，任何时候都去查询或询问最新的接收地址，并且反复确认。依赖的越少，出错的概率越小。 
 - 大额或首次转给某个地址的时候，先打一笔小额的测试一下。 

### 3.7 DAPP
DAPP即去中心化应用，感观上和普通网页无异，但是可以和区块链协议的网络交互，可以直接在页面上展示某个账户的信息和进行特定操作。 

访问[https://debank.com/](https://debank.com/)可以很方便的查看各种DAPP，DAPP一般都有自己的访问网址。比如Pancake的网址是：[https://pancakeswap.finance/](https://pancakeswap.finance/)，Beefy的网址是：[https://www.beefy.finance/](https://www.beefy.finance/)。 

使用DAPP，需要解决上述“和区块链协议的网络交互”，实现方式有两种，一种是使用手机钱包的内置浏览器，一种是使用桌面的Chrome浏览器配合浏览器插件钱包。 

 - 手机钱包的内置浏览器

    钱包一般有内置浏览器，浏览器中列出了常见的DAPP，可以直接点击访问，也可以找到输入网址的地方输入网址然后打开访问。 

 - Chrome浏览器配合浏览器插件钱包

    一般使用的插件是MetaMask，在Chrome的插件应用市场中搜索MetaMask安装即可。 

MetaMask和前面介绍的手机钱包类似，也需要导入助记词使用。MetaMask有一个特殊之处是只能导入一个助记词，其余只能导入私钥。建议的方式是用手机钱管理多个助记词，从手机钱包导出私钥再导入到MetaMask中使用。 

不论是上述哪种方式，在使用DAPP的时候体验都比较类似。 

一般DAPP网页的右上角账户信息区都会展示当前“和区块链协议的网络交互”的账号，在使用时注意核对。 

DAPP中的变更操作一般都是发起一笔交易，交易在发起时都会弹出交易相关的信息，包括交互的智能合约地址，涉及的转账数额，手续费数额，要注意核对。手机钱包中发起交易的时候，会提示输入密码，填入生成或导入助记词时设置的密码。 

每个DAPP的功能，流程，逻辑都是根据自身业务特点设计出来的，需要根据其界面信息，基本知识和使用其他应用包括传统互联网应用的经验去掌握。 

### 3.8 稳定币
在加密世界，一般大家谈论加密资产的价格还是美元计价，但是交易并不是直接与美元交易，而是与和美元锚定的稳定币进行交易，这一做法的好处是：稳定币是构建在加密世界得基础设施上的，可以用加密世界的账本记账，如此应用和服务只要和这个账本交互即可，不再需要和真实世界的法币系统交互。 

目前最成功的稳定币是USDT，此外比较常用的还有PAX，USDC，BUSD，DAI。

### 3.9 交易所
交易所承担了价值中介的角色，是加密世界最重要的基础设施。绝大多数持币者的币都保存在交易所里，他们甚至不知道如何使用钱包。 

目前比较知名的交易所有coinbase [https://www.coinbase.com](https://www.coinbase.com)，币安 [https://www.binance.com](https://www.binance.com)，火币 [https://www.huobi.com](https://www.huobi.com)。 

交易所本质也是一个记账账本，但不是一个去中心化的账本，是去中心化原教旨主义者比较反对的。但是“存在即合乎理性”，完全消除中心化既不现实，也无必要。 

熟悉股票交易的人，对加密资产交易所不会陌生，一般都有资产列表，行情，交易的蜡烛图，订单簿，成交记录，深度，可以下限价单，市价单。 

唯一需要并且要深刻认识的是加密资产交易所的出入金方式。交易所会给每个用户的每种资产生成一个专用的入金地址，当有任何人往这个地址转资产的时候，交易所都会监控到，并且把用户的余额增加对应的金额，那笔资产事实上进入了交易所的钱包，交易所对其进行代管。当用户要出金的时候，只需要把接收地址和金额录入到交易所的出金界面，交易所会从其钱包中转出到出金地址，并且把用户的余额减少对应的金额。常见的操作是把把资产从一个交易所转移到另一个交易所，只需要在一个交易所出金，出金地址填写另一个交易所的入金地址即可。 

正是因为交易所这种中心化系统中间都是以区块链网络为中介，让全世界大大小小的独立交易所，可以顺畅的相互转移加密资产，让加密资产金融业务可以非常迅速的创新。 

### 3.10 C2C交易
因为监管的原因，加密资产和法币之间的兑换并没有实现成购买虚拟商品这么简单直接，而是逐渐发展成以C2C交易为主，即Customer to Customer交易。 

C2C交易一般也是交易所开设，比如火币和币安。C2C交易中，任何环节，法币资产都不会被平台代管，平台只是为买卖双方建立联系和管理整个交易过程。 

兑换是这样进行的，明确交易的法币数额和加密资产数额后，平台先冻结加密资产，然后法币一方通过个人到个人的转账方式将法币转给加密资产一方，后者通知平台收到了法币，平台把冻结的加密资产划拨给法币一方。所以，如果你是购买加密资产，则需要把法币打给对方账号，如果你是出售加密资产，则要确定收到对方的法币之后再通知平台已收到。 

C2C交易风险较大，不确定性比较大，除了遇到不守规则的交易对象，最大的风险是收到黑钱被冻卡。所以当你购买加密资产的时候，对方会不厌其烦的让你提供银行流水，交易所界面录屏，都是为了防止你的钱是黑钱，要予以理解，而如果你出售加密资产的时候，一定要好好规划单次交易的金额，收法币的银行卡，对对方是否会转黑钱没有鉴定能力则选择平台提供的蓝盾认证。
